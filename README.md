My personal portfolio: selected work, experience, stack and certifications, in English and Spanish.

## Highlights

- **Zero build step** — one static `index.html`, deployed with GitHub Pages
- **Bilingual** EN / ES and **light / dark** theme, remembered per visitor
- **Motion with restraint** — masked headline reveal, blur-up section reveals, clip-path image reveals,
  animated SVG/CSS project panels and Lenis smooth scrolling
- **Accessible** — respects `prefers-reduced-motion`, keyboard focus styles, semantic sections
- **Fast** — system of CSS tokens, no framework, lazy-loaded images

## Structure

```
index.html   page, styles and behavior
work/        project screenshots
profile.jpeg portrait
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
